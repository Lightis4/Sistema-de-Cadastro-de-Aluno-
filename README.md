🎓 Sistema de Cadastro de Alunos

Projeto desenvolvido em Python com o objetivo de praticar programação modular, trabalho em equipe utilizando Git e GitHub, além do uso de branches e pull requests.

## 📋 Funcionalidades

- Cadastro de alunos
- Listagem de alunos
- Edição de alunos
- Remoção de alunos
- Menu interativo


## 📁 Estrutura do Projeto

sistema_alunos/
│
├── main.py
├── cadastro_aluno.py
├── listar_alunos.py
├── editar_aluno.py
├── remover_aluno.py
└── dados.py


## 🚀 Como executar

1. Clone o repositório:

bash
git clone <url-do-repositorio>


2. Entre na pasta do projeto:

cd sistema_alunos

3. Execute o arquivo principal:

bash
python main.py


## 👥 Organização da Equipe

A branch `main` é protegida e utilizada apenas para integração das funcionalidades.

Cada integrante deve trabalhar em sua própria branch.

Responsabilidades

Integrante 1

Branch:

```bash
feature-cadastro
```

Arquivo:

```text
cadastro_aluno.py
```

Responsável pelo cadastro dos alunos.


Integrante 2

Branch:

```bash
feature-listagem
```

Arquivo:

```text
listar_alunos.py
```

Responsável pela listagem dos alunos.

Integrante 3

Branch:

```bash
feature-editar
```

Arquivo:

```text
editar_aluno.py
```

Responsável pela edição dos dados dos alunos.

Integrante 4

Branch:

```bash
feature-remover
```

Arquivo:

```text
remover_aluno.py
```

Responsável pela remoção de alunos.


 🔀 Fluxo de Trabalho com Git

Criar uma nova branch:

```bash
git checkout -b nome-da-branch
```

Adicionar alterações:

```bash
git add .
```

Criar commit:

```bash
git commit -m "Descrição da alteração"
```

Enviar para o GitHub:

```bash
git push origin nome-da-branch

Após concluir a funcionalidade:

1. Abrir um Pull Request.
2. Solicitar revisão.
3. Aguardar aprovação.
4. Realizar merge na branch `main`.
